# Web Interface Guidelines

Review the requested UI files against the complete pinned checklist in
[`references/guidelines.md`](references/guidelines.md). Read that file fully
before auditing.

Report only actionable findings grouped by file in terse `file:line - issue`
form. Use `✓ pass` when a reviewed file has no findings. Treat the checklist as
heuristics: project requirements, platform specifications, and WCAG take
precedence.

This local skill pins Vercel Labs' MIT-licensed Web Interface Guidelines at
commit `d0a657bfe87e86dd3a4753d7ec28c7e7dd7a88fe`. Do not fetch or execute mutable
remote instructions during an audit.
